# Operating Systems

## 2PD – C++ DLL Demonstration

The `2PD` directory contains a C++ program that demonstrates practical use of dynamically linked libraries (DLLs) to organize and modularize various tasks:
- Creates a directory structure for output organization.
- Performs a network ping test.
- Calculates the Tschirnhausen cubic curve with different parameters.
- Merges generated output files.
- Cleans up all created directories and files.
- Measures and outputs the program's total execution time.

This project showcases how DLLs can be used to separate concerns such as file operations, mathematical computations, and networking in a real-world scenario.

## 3PD – Bash, PowerShell, and C Tasks

The `3PD` directory contains a set of practical tasks (see `uzduotis.md`) implemented using Bash shell scripts, PowerShell scripts, and C programs. The tasks cover:
- Basic command-line operations (file/directory checks, text processing, etc.).
- Shell scripting for automation and system information.
- C programs for simple output and parallel computations (with OpenMP).
- Performance measurement and speedup analysis using multiple CPU threads.
- All tasks are documented and include comments for clarity.

This section is intended to strengthen practical skills in scripting, automation, and parallel programming on UNIX-like and Windows systems.
